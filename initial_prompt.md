PBX - Pocketbase Extended
It is a personal database with AI capabilities built-in, base on Pocketbase.
PBX add to pocketbase configurable UI to view and edit collections, Lua scripting for actions, export/import from Excel and external MSSQL database and reports with print to PDF. 
Configuration is stored in collection too, those “setup collections” has names with leading “_”. Setup contain definitions of all different views (list, card/kanban,view of detail, edit/create form, report… ). Inside the setup collection record the configurations are stored in JSON fields. For example JSON definition of list containn setting of which columns are displayed in the list (table view), which columns allow setting of sort, which columns are included in search, definitions of filters with parameters, row and bulk actions in Lua etc.). The will be “configuration editor” pages in PBX, with super-admin access only, which present web forms to edit configuration in user friendly manner.
There can be more than 1 configurations for one collection, which allow different ways of presenting the same collection in UI (for example more list view with different set of columns etc.). Each configuration record has a “_name” filed with unique name of the configuration which will be used by endpoint then (for example “{URL}/tabular/{configuration_name}").
There will be also possibility to create PB collection from Excel of MSSQL database. PBX introspect the Excel or MSSQL db and create collection fit the this datasource schema. 
Extend actual export/import (Excel) capabilities by adding exp/imp from MSSQL database (mapping of collection fields with db table fields will be part of configuration, JSON field “_MSSQL”, where the DSN is stored as well).
In the PBX the pocketbase “view only” collection can be edited as well. If the view-only collection is joined from more base collections (by JOIN statement) the edit/create form present on one page forms for all those base collection.
Let start from existing PBX design and status of development and create the implementation according above requests.
